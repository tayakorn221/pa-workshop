เริ่มใน 5 นาที

อยากลองกรอกผลเลย — ทำ 3 ขั้นนี้

ทางลัดสำหรับคนที่อยากลงมือทันที · อยากเข้าใจเต็ม ๆ เลื่อนลงอ่าน M0–M5 ด้านล่าง

  1. เข้าสู่ระบบ ที่ pa.kmutt.ac.th ด้วยอีเมล มจธ. และรหัสผ่านของคุณ
  2. เปิด "ภาพรวมผลดำเนินงาน" → คลิกชื่อตัวชี้วัด ที่ยังไม่กรอก → เปิดหน้า KPI Hub ในแท็บใหม่
  3. เลือก รอบ (เช่น M9 มิ.ย.) → กรอก ผลดำเนินงาน + หมายเหตุ → กด "บันทึกร่าง"

ครบ 3 ขั้น = คุณกรอกผลเป็นแล้ว · ติดปัญหา? ดู FAQ หรือทักทีมผู้ดูแลที่ท้ายหน้า

เปิด

ระบบ PA คืออะไร และวันนี้คุณจะได้อะไร

10 นาที

PA (Performance Agreement · ข้อตกลงการปฏิบัติงาน) คือระบบติดตามผลการดำเนินงานของหน่วยงานตาม PA ที่รับผิดชอบในแต่ละปีงบประมาณ — PA ของแต่ละหน่วยงานคือชุดตัวชี้วัดที่มีเป้าหมายและน้ำหนัก บทบาทของคุณคือ requester ผู้กรอกผลดำเนินงานของหน่วยงานตัวเอง ทุกอย่างวันนี้ทำบนระบบจริงที่ pa.kmutt.ac.th

วันนี้คุณจะได้เรียนรู้และลงมือทำ

  • M0 · เข้าสู่ระบบ — login ด้วยอีเมล มจธ. และตั้ง/รีเซ็ตรหัสผ่านได้เอง
  • M1 · อ่าน PA ของหน่วยงาน — รู้ว่ามีตัวชี้วัดอะไร เป้าหมายเท่าไร น้ำหนักเท่าไร ตัวไหนยังไม่กรอก
  • M2 · คำขอเปลี่ยนแปลง PA — ขอแก้เป้าหมาย / น้ำหนัก / เพิ่ม-ลบตัวชี้วัด แล้วติดตามสถานะคำขอ
  • M3 · กรอกผลดำเนินงาน ⭐ — กรอกผลรายรอบแล้วบันทึกร่าง (โมดูลหลักของวันนี้)
  • M4 · โครงการ / แผนปฏิบัติการ — รู้จัก wizard สร้างโครงการ 7 ขั้น
  • M5 · ติดตามสถานะ & รายงาน — อ่านสถานะ + ไฟจราจร และรู้ว่าผลแบบไหนเข้ารายงาน

สรุป 3 ขั้นที่ต้องจำให้ได้: เข้าสู่ระบบ → เปิดดู PA → กรอกผล + บันทึกร่าง

M0 · เข้าสู่ระบบ →
M0

เข้าสู่ระบบ

15 นาทีข้ามได้

เป้าหมาย: เข้าสู่ระบบได้เอง และตั้งรหัสผ่านครั้งแรกเป็น

เข้าระบบด้วยอีเมล มจธ. — คนใหม่จะได้รับอีเมลคำเชิญเพื่อตั้งรหัสผ่าน ส่วนคนที่ลืมรหัสขอใหม่ได้

สาธิต

  1. ที่หน้า PA Tracking กรอก อีเมล + รหัสผ่าน → กดปุ่ม "เข้าสู่ระบบ"
  2. คนใหม่: เปิดอีเมลคำเชิญ → หน้า "ตั้งรหัสผ่าน" → กรอก รหัสผ่านใหม่ (อย่างน้อย 8 ตัว) + ยืนยันรหัสผ่าน → ดูแถบความแข็งแรง (อ่อน / พอใช้ / ดี / ดีมาก) → กด "บันทึกรหัสผ่าน" → ขึ้น "ตั้งรหัสผ่านสำเร็จ" → เข้าหน้าหลัก
  3. ลืมรหัสผ่าน: กดลิงก์ "ลืมรหัสผ่าน?" → กรอกอีเมล → กดปุ่ม "ส่งลิงก์"

ถ้าลิงก์ตั้ง/รีเซ็ตรหัสใช้ไม่ได้: ต้องเปิดลิงก์ในเบราว์เซอร์เดียวกับที่กดขอ (เปิดคนละเครื่อง/คนละเบราว์เซอร์จะขึ้น "ลิงก์ไม่สามารถใช้ได้ในเบราว์เซอร์นี้…") · ถ้าอีเมลหรือรหัสผ่านผิดจะขึ้น "อีเมลหรือรหัสผ่านไม่ถูกต้อง"

M1

อ่าน PA ของหน่วยงาน

25 นาทีอ่าน

เป้าหมาย: อ่าน PA ของหน่วยงานเป็น — รู้ว่ามีตัวชี้วัดอะไร เป้าเท่าไร น้ำหนักเท่าไร ตัวไหนยังไม่กรอก

แนวคิด: PA ของหน่วยงานคือชุดของหลาย ตัวชี้วัด — แต่ละตัวมี เป้าหมาย และ น้ำหนัก (รวมทุกตัว = 100%) ผลที่กรอกจะถูกแปลเป็น ไฟจราจร และมี สถานะ ของการทำงานกำกับ

สาธิต — 2 หน้าที่ต้องรู้จัก

  • ภาพรวมผลดำเนินงาน (/dashboard) — ตารางคะแนน: คอลัมน์ รหัส / ชื่อ / ผลลัพธ์ (ไฟจราจร) / สถานะ / งวด (รอบล่าสุดที่กรอก) + การ์ดคะแนนรวม + แถบแจ้งเตือน · คลิกชื่อตัวชี้วัด เพื่อเปิดหน้า KPI Hub ในแท็บใหม่
  • ตัวชี้วัดของหน่วยงาน (/my-pa, หัวข้อ "ตัวชี้วัดของหน่วยงานฉัน") — สรุป "ตัวชี้วัด N รายการ · น้ำหนักรวม X%" (กลายเป็นสีเหลืองถ้า ≠ 100%) + ตาราง รหัส / ชื่อตัวชี้วัด / เป้าหมาย / น้ำหนัก / หน่วยวัด / การดำเนินการ

ลงมือทำ

เปิด /my-pa เพื่ออ่าน PA ของตัวเอง: มีกี่ตัวชี้วัด น้ำหนักรวมเท่าไร แล้วเปิด /dashboard หาว่าตัวไหนคอลัมน์ "งวด" ยังเป็น —

ทดสอบความเข้าใจ

น้ำหนักของตัวชี้วัดทุกตัวในหน่วยงานรวมกันควรเท่ากับเท่าไร?

เฉลย: น้ำหนักรวมทุกตัวชี้วัด = 100% — ถ้าไม่ครบ 100% สรุปด้านบนของหน้า "ตัวชี้วัดของหน่วยงาน" จะกลายเป็นสีเหลือง

M2

คำขอเปลี่ยนแปลง PA

25 นาทีส่งจริงรอบนี้

เป้าหมาย: ปรับ PA ของหน่วยงานให้ถูกต้องเป็น — เปลี่ยนเป้า / น้ำหนัก / เพิ่ม-ลบตัวชี้วัด แล้วติดตามสถานะคำขอ

แนวคิด: อยากแก้ PA → ส่ง "คำขอเปลี่ยนแปลง" รอบนี้ window อนุมัติอัตโนมัติเปิดอยู่ → คำขออนุมัติทันที มีผลกับ PA จริงเลย (ปกตินอกช่วงนี้ admin เป็นผู้อนุมัติ)

สาธิต + ลงมือทำ

ที่ /my-pa กดเมนู "การดำเนินการ" (จุด 3 จุด) จะมี 4 แบบให้เลือก dialog แต่ละแบบมีช่อง ค่าใหม่ + เหตุผล* แล้วกด "ส่งคำขอ" · ติดตามได้ที่ /my-change-requests

ในหน้า "ขอเพิ่มตัวชี้วัด" มีสวิตช์ "สร้างตัวชี้วัดใหม่ (ไม่อยู่ในรายการ)" — เปิดแล้วระบบจะสร้างรหัสให้เอง (รูปแบบ DEPT-xxx-NNN)

ทบทวน PA จาก M1 — ถ้าต้องแก้ (เช่น น้ำหนักรวมยังไม่ครบ 100% หรือเป้าไม่ตรง) กรอกค่าใหม่ + เหตุผล แล้วกด "ส่งคำขอ" จริง จะขึ้น "อนุมัติแล้ว — มีผลทันที"

ทดสอบความเข้าใจ

ถ้าต้องการแก้เป้าหมายหรือน้ำหนักของตัวชี้วัด ต้องทำอย่างไร?

เฉลย: แก้เองในตารางไม่ได้ — ต้องส่ง "คำขอเปลี่ยนแปลง" · รอบอบรมนี้ window อนุมัติอัตโนมัติเปิดอยู่จึงมีผลทันที (ปกตินอกช่วงนี้ admin เป็นผู้อนุมัติ)

M3 ★ โมดูลหลัก

กรอกผลดำเนินงาน

45 นาที · ลงมือทำหลักบันทึกร่างเท่านั้น

เป้าหมาย: กรอกผลรายรอบแล้ว บันทึกร่าง ได้เอง และแยกออกว่า "ร่าง" ต่างจาก "ส่งรายงาน" อย่างไร

แนวคิด: แต่ละตัวชี้วัดกรอกผลแยกตามรอบ (M1–M12 รายเดือน, H1/H2 รายครึ่งปี) วันนี้ใช้รอบ M9 (มิ.ย.) กรอกผลเป็นตัวเลข ระบบมีเพดานที่ 120% (กรอกเกิน 100% ได้ แต่คะแนนตันที่ 120%)

  • ร่าง = เซฟไว้ แก้ได้ ยังไม่ส่ง
  • ส่งรายงาน = ส่งให้ admin แล้วล็อก แก้ไม่ได้จนกว่าจะถูกส่งกลับ

สาธิต — หน้า KPI Hub (/progress/[assignmentId])

  1. จาก "ภาพรวมผลดำเนินงาน" คลิกชื่อตัวชี้วัด → เปิด KPI Hub ในแท็บใหม่
  2. เลือก รอบ → เลือก M9 (มิ.ย.)
  3. การ์ด "กรอกผลดำเนินงาน" แสดงป้ายสถานะ + "เป้าหมาย: X | น้ำหนัก: Y%"
  4. ช่อง กิจกรรม — เลือกได้ถ้ามีโครงการผูกอยู่ (ไม่บังคับ; ถ้าไม่มีจะไม่โชว์)
  5. ช่อง ผลดำเนินงาน (หน่วย) — กรอกเป็นตัวเลข
  6. ช่อง หมายเหตุ
  7. กด "บันทึกร่าง" → ขึ้น "บันทึกร่างสำเร็จ" → ช่อง แนบเอกสารหลักฐาน จะปรากฏ (ก่อนบันทึกจะขึ้นข้อความ "บันทึกร่างก่อนเพื่อแนบเอกสารหลักฐาน")

ลงมือทำ (quick win)

กรอกผลทดสอบ ใส่คำว่า "ทดสอบอบรม" ในช่องหมายเหตุ แล้วกด "บันทึกร่าง" ให้ได้ข้อความ "บันทึกร่างสำเร็จ"

ทดสอบความเข้าใจ

หลังกรอกผลแล้วกด "บันทึกร่าง" — สถานะจะเป็นอะไร และส่งถึง admin หรือยัง?

เฉลย: "บันทึกร่าง" = สถานะ "ร่าง" เซฟไว้แก้ได้ ยังไม่ส่ง · ต้องกด "ส่งรายงาน" ถึงจะเข้าคิว admin (วันนี้ฝึกแค่ "บันทึกร่าง" พอ)

M5

ติดตามสถานะ & รายงาน

15 นาทีอ่าน

เป้าหมาย: อ่านสถานะเป็น และรู้ว่าผลแบบไหนเข้ารายงาน

เรื่องที่คนสับสนบ่อยที่สุดคือ ป้าย 2 ตระกูล — "สถานะ" (ขั้นตอนการทำงาน) กับ "ผลลัพธ์" (ไฟจราจร) เป็นคนละเรื่องกัน

ผลลัพธ์ (ไฟจราจร)

  • บรรลุเป้า≥ 100%
  • ใกล้เป้า≥ 80%
  • ยังไม่ถึงเป้า< 80%
  • ไม่มีข้อมูลยังไม่กรอก

สถานะ (ขั้นตอนการทำงาน)

  • ร่างแก้ได้
  • รอรีวิวล็อก รอ admin
  • อนุมัติแล้วล็อก · ขึ้น PDF
  • ส่งกลับแก้ไขแก้ได้

"สถานะ" บอกว่ากำลังอยู่ขั้นไหน · "ผลลัพธ์" บอกว่าทำได้กี่ % — คนละแกนกัน

  • เฉพาะผลที่สถานะ "อนุมัติแล้ว" เท่านั้นที่ขึ้นรายงาน PDF
  • คอลัมน์ "งวด" = รอบล่าสุดที่กรอก
  • ถ้าสถานะเป็น "ส่งกลับแก้ไข" จะเห็นข้อความ "เหตุผลที่ส่งกลับ:" แนบมาด้วย
  • เมนู "รายงาน" เป็นของ admin — requester ดูคะแนนผ่าน dashboard ของตัวเอง
ทดสอบความเข้าใจ

ผลแบบไหนที่จะแสดงในรายงาน PDF?

เฉลย: เฉพาะผลที่สถานะ "อนุมัติแล้ว" เท่านั้นที่ขึ้นรายงาน PDF · ไฟจราจร (ผลลัพธ์) เป็นคนละแกนกับสถานะ — สีเขียวแต่ยังเป็น "ร่าง" ก็ยังไม่ขึ้นรายงาน

ปัญหาที่พบบ่อย

เปิดอ่านเฉพาะข้อที่ติด

คำถามที่เจอบ่อยตอนใช้งานจริง — คลิกเพื่อดูคำตอบ

ลืมรหัสผ่าน เข้าระบบไม่ได้ ทำยังไง?

ที่หน้าเข้าสู่ระบบ กดลิงก์ "ลืมรหัสผ่าน?" → กรอกอีเมล มจธ. → กด "ส่งลิงก์" แล้วเปิดลิงก์ในอีเมล

สำคัญ: ต้องเปิดลิงก์ใน เบราว์เซอร์เดียวกับที่กดขอ — ถ้าเปิดคนละเครื่อง/คนละเบราว์เซอร์จะขึ้น "ลิงก์ไม่สามารถใช้ได้ในเบราว์เซอร์นี้…" · ถ้าลิงก์หมดอายุหรือถูกใช้แล้ว ขอลิงก์ใหม่ได้

กรอกผลแล้ว ทำไมไม่เห็น / เหมือนหาย?

เช็ก 3 อย่าง:

1. กดปุ่ม "บันทึกร่าง" จนขึ้น "บันทึกร่างสำเร็จ" แล้วหรือยัง
2. กำลังดู รอบ (งวด) เดียวกัน กับที่กรอกไหม — ผลแยกตามรอบ M9 อยู่คนละช่องกับ M8
3. กำลังดูตัวชี้วัดตัวเดียวกันไหม

ผลที่ "บันทึกร่าง" ไว้ไม่หาย แต่จะยังไม่ขึ้นรายงานจนกว่าจะ "ส่งรายงาน" แล้ว admin "อนุมัติแล้ว"

น้ำหนักรวมไม่ครบ 100% ต้องแก้ยังไง?

เปิด "ตัวชี้วัดของหน่วยงาน" (/my-pa) — สรุปด้านบนจะเป็นสีเหลืองถ้าน้ำหนักรวม ≠ 100% → กดเมนู "การดำเนินการ" (จุด 3 จุด) ของตัวชี้วัดที่ต้องการ → เลือกขอแก้น้ำหนัก กรอกค่าใหม่ + เหตุผล → กด "ส่งคำขอ"

รอบอบรมนี้ window อนุมัติอัตโนมัติเปิดอยู่ คำขอจึงมีผลทันที

กรอกผลได้เกิน 100% ไหม?

ได้ กรอกค่าจริงได้เลย แต่คะแนนจะตันที่ 120% (เพดานของระบบ) — กรอกได้เกิน 100% แต่คะแนนสูงสุดที่นับให้คือ 120%

"สถานะ" กับ "ผลลัพธ์" ต่างกันยังไง?

"สถานะ" = ขั้นตอนการทำงาน (ร่าง / รอรีวิว / อนุมัติแล้ว / ส่งกลับแก้ไข)

"ผลลัพธ์" = ไฟจราจรว่าทำได้กี่ % (บรรลุเป้า / ใกล้เป้า / ยังไม่ถึงเป้า / ไม่มีข้อมูล)

เป็นคนละแกนกัน — ผลเป็นสีเขียวแต่สถานะยังเป็น "ร่าง" ก็ยังไม่เข้ารายงาน

ผลถูก "ส่งกลับแก้ไข" ต้องทำยังไง?

เปิดตัวชี้วัด/รอบนั้น จะเห็นข้อความ "เหตุผลที่ส่งกลับ:" แนบมา → แก้ตามเหตุผล → กด "ส่งรายงาน" อีกครั้งเพื่อส่งกลับเข้าคิวรีวิว

สถานะ "ส่งกลับแก้ไข" แก้ได้ (ต่างจาก "รอรีวิว"/"อนุมัติแล้ว" ที่ล็อกไว้) · ถ้ายังติด ติดต่อทีมผู้ดูแลที่ท้ายหน้า
