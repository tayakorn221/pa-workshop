# เว็บสอนการใช้งานระบบติดตาม PA

สื่อการอบรม **"การใช้งานระบบติดตาม PA"** สำหรับเจ้าหน้าที่หน่วยงาน (requester) ของ มจธ. —
ใช้เรียนด้วยตัวเองหรือฉายประกอบการอบรมในห้องได้

## 🔗 เปิดใช้งาน

**https://tayakorn221.github.io/pa-workshop/**

เปิดลิงก์ในเบราว์เซอร์ได้เลย (คอมพิวเตอร์ / แท็บเล็ต / มือถือ)

## วิธีใช้

- **เรียนเอง:** เลื่อนอ่านทีละโมดูล · คลิกเมนูด้านซ้ายเพื่อกระโดดไปหัวข้อ · ติ๊ก checkpoint ได้ (จำความคืบหน้าไว้ในเครื่อง)
- **ฉายในห้องอบรม:** เปิดเต็มจอด้วย `F11` — ตัวอักษรใหญ่อ่านง่ายบนจอโปรเจกเตอร์
- **ออฟไลน์:** เป็นไฟล์ HTML ไฟล์เดียวจบในตัว ดาวน์โหลด [`index.html`](index.html) ไปเปิดแบบดับเบิลคลิกได้ (ไม่ต้องต่อเน็ต ยกเว้นโหลดฟอนต์)

## เนื้อหา

| โมดูล | หัวข้อ |
|---|---|
| เปิด | แนะนำระบบ + สิ่งที่จะได้เรียนรู้ |
| M0 | เข้าสู่ระบบ (ตั้งรหัส / ลืมรหัส) |
| M1 | อ่าน PA ของหน่วยงาน |
| M2 | คำขอเปลี่ยนแปลง PA |
| M3 ⭐ | กรอกผลดำเนินงาน (โมดูลหลัก) |
| M4 | โครงการ / แผนปฏิบัติการ (wizard) |
| M5 | ติดตามสถานะ & รายงาน |
| ปิด | สรุป + อภิธานศัพท์ + ช่องทางขอความช่วยเหลือ |

แต่ละโมดูลมีภาพประกอบจากระบบจริง + checkpoint สำหรับวัดความเข้าใจ
