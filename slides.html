เปิด

PA คืออะไร

  • PA = ชุดตัวชี้วัดของหน่วยงานในแต่ละปีงบประมาณ (มีเป้าหมาย + น้ำหนัก รวม 100%)
  • บทบาทของคุณ = requester — ผู้กรอกผลของหน่วยงานตนเอง
  • วันนี้ฝึกบนระบบจริง pa.kmutt.ac.th · กรอกผลให้กด "บันทึกร่าง" เท่านั้น · โครงการคงไว้เป็นฉบับร่าง

M0

เข้าสู่ระบบ

  • เข้าด้วย อีเมล มจธ. + รหัสผ่าน
  • คนใหม่: ตั้งรหัสผ่านจาก อีเมลคำเชิญ
  • ลืมรหัส: กด "ลืมรหัสผ่าน?" — เปิดลิงก์ในเบราว์เซอร์เดียวกับที่กดขอ

M1

อ่าน PA ของหน่วยงาน

  • 2 หน้าที่ต้องรู้จัก: "ภาพรวมผลดำเนินงาน" + "ตัวชี้วัดของหน่วยงาน"
  • ตอบให้ได้: มีกี่ตัวชี้วัด · เป้า/น้ำหนัก (รวม 100%) · ตัวไหนยังไม่กรอก

M2

คำขอเปลี่ยนแปลง PA

  • แก้ เป้าหมาย / น้ำหนัก / เพิ่ม-ลบตัวชี้วัด
  • ทำผ่านเมนู "การดำเนินการ" → "ส่งคำขอ"
  • ตามปกติคำขอ เข้าคิวให้ผู้ดูแลพิจารณา → ไม่มีผลทันที

M3

โครงการ

  • สร้างผ่าน wizard 7 ขั้น
  • ฉบับร่าง ปลอดภัย — แก้/ลบได้ ยังไม่ใช้งานจริง
  • "บันทึกและส่งโครงการ" = ยืนยันส่ง (วันนี้อย่ากด)

M4 · โมดูลหลัก

กรอกผลดำเนินงาน

  • คลิกชื่อตัวชี้วัด → หน้ากรอกผล PA
  • เลือก รอบ (เช่น M9) → กรอกผล + หมายเหตุ → "บันทึกร่าง"
  • ร่าง = แก้ได้ ยังไม่ส่ง · กรอกเกินเป้าได้ แต่คะแนนตันที่ 100%

M5

ติดตามสถานะ & รายงาน

  • 2 แกน คนละเรื่อง
  • สถานะ = ขั้นตอน (ร่าง / รอรีวิว / อนุมัติแล้ว / ส่งกลับแก้ไข)
  • ผลลัพธ์ = เขียว เหลือง แดง (บรรลุ / ใกล้ / ยังไม่ถึงเป้า)
  • เฉพาะ "อนุมัติแล้ว" เท่านั้นที่ขึ้นรายงาน PDF

สรุป

3 ขั้นที่ต้องจำ

1เข้าระบบ login ด้วยอีเมล มจธ.
2เปิดดู PA คลิกตัวชี้วัด → หน้ากรอกผล PA
3กรอกผล + บันทึกร่าง เลือกรอบ กรอกเลข แล้วบันทึกร่าง
